# Flint
A music player with timed-sync lyrics.

## Getting Started

To run this application:

```bash
bun install
bun run dev
```

## Styling

This project uses [Tailwind CSS](https://tailwindcss.com/) for styling, and [shadcn](https://ui.shadcn.com/) for components.

## Routing
This project uses [TanStack Router](https://tanstack.com/router).
